# Этап 55 — объединение DOCX со сносками

## Что сделано
- Переносит сноски и концевые сноски из добавляемых DOCX при объединении документов.
- Перенумеровывает примечания и ссылки, чтобы идентификаторы из исходных файлов не конфликтовали.
- Переносит связи примечаний с изображениями и внешними ссылками безопасным способом.
- Для повреждённого DOCX со ссылкой на отсутствующую часть примечаний возвращает понятную ошибку.
- Добавлены автоматические тесты на обе разновидности примечаний, перенумерацию и повреждённую ссылку.

## Проверка
- До изменений исходный набор: 62/62 теста.
- После изменений: `compileall` прошёл; 64/64 unit-теста прошли в локальном Windows runtime.
- Проверка выполнена без запуска GUI; визуальная проверка итогового DOCX в Word/LibreOffice остаётся ручной.
- GitHub Actions для этапа 55 ещё не запускался.

## Ограничения
- Сложные связанные объекты Word, кроме изображений и внешних ссылок, могут вызвать безопасный отказ объединения.
- Ручная проверка отображения сносок в Microsoft Word не выполнялась.
