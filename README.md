# DOCX Helper

Генератор и помощник для подготовки документов DOCX и презентаций PPTX по ГОСТ.

## Запуск в Windows

1. Установите Python 3.10 или новее.
2. Запустите `install_dependencies.bat` либо установите зависимости командой `py -3 -m pip install -r requirements.txt`.
3. Запустите приложение: `py -3 123.py`.

В репозитории есть встроенный стартовый шаблон PPTX. Другие шаблоны добавляются пользователем в библиотеку приложения.

## Проверка

Из папки проекта выполните:

```powershell
py -3 -m compileall -q .
py -3 -m unittest discover -s tests -v
```

GUI нужно проверить в Windows отдельно по ручному списку из архива проекта.

## Обновления

Приложение проверяет HTTPS-манифест `updates.json` и показывает ссылку на страницу релизов. Оно не устанавливает обновления автоматически. Для выпуска новой версии обновите версию в `updates.json` и опубликуйте релиз на GitHub.

Текущая версия исходников: **8.0.0**.
